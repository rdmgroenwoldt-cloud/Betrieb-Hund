# Flyer-Anleitung — Tierschutzvereine

Der Flyer liegt unter `tierschutzverein-flyer.html` und ist im A4-Hochformat
(210 × 297 mm). Er funktioniert sowohl gedruckt zum Aushängen als auch
digital als Bild oder PDF für WhatsApp / E-Mail.

Live im Browser ansehen:
**https://rdmgroenwoldt-cloud.github.io/Betrieb-Hund/flyer/tierschutzverein-flyer.html**

## Variante A — Flyer drucken (zum Aushängen)

1. Im Browser öffnen
2. **Strg + P** (Drucken)
3. Im Druck-Dialog:
   - **Drucker** wählen
   - **Ränder: Keine** (sonst weißer Rand drumherum)
   - **Hintergrundgrafiken**: ✅ **aktivieren** — sonst kommt das Royal+Wein nicht durch und der Flyer ist halb weiß
   - **Skalierung: 100 %**
4. Drucken

## Variante B — Flyer als PDF speichern (für E-Mail)

1. Im Browser öffnen
2. **Strg + P**
3. Als Drucker **„Als PDF speichern"** (bei Chrome) oder
   **„Microsoft Print to PDF"** (bei Edge) wählen
4. Gleiche Einstellungen wie oben (Ränder „Keine", Hintergrundgrafiken ✅)
5. **Speichern** → PDF liegt jetzt auf Eurem Rechner
6. PDF an Adoptanten per E-Mail schicken

## Variante C — Flyer als Bild für WhatsApp

WhatsApp zeigt Bilder direkt in der Chatansicht — viel besser als ein PDF-Anhang.

**Schnellste Methode (Windows):**
1. Flyer im Browser öffnen
2. Fenster auf große Größe ziehen damit der ganze Flyer sichtbar ist
3. **Windows-Taste + Shift + S** öffnet das Snipping-Tool
4. Den **kompletten Flyer-Bereich** (das Royal+Wein-Blatt) markieren
5. Bild ist automatisch in der Zwischenablage
6. Direkt in WhatsApp einfügen mit Strg + V — oder mit „Datei → speichern unter" als PNG sichern

**Alternative (sauberer):**
1. PDF wie in Variante B erstellen
2. PDF → PNG online umwandeln, z.B. https://smallpdf.com/de/pdf-in-png oder
   https://www.ilovepdf.com/de/pdf_zu_jpg
3. Das PNG/JPG in WhatsApp einfügen

## QR-Codes aufkleben (personalisiert pro Verein)

Der Flyer hat **zwei leere QR-Code-Felder** mit gestrichelter Umrandung
direkt unter den Eckdaten:

1. **Anmeldung zum Beratungsabend** — Code zur Eintragungs-Liste
2. **Termin direkt buchen** — Code zum Calendly/Kalender für ein
   persönliches Vorgespräch

Beide werden pro Verein **individuell erzeugt** (jeder Stall bekommt
seinen eigenen Tracking-Link) und nach dem Druck einfach
**auf das jeweilige Feld geklebt**. Die Felder sind 42 × 42 mm groß —
passt für klassische QR-Code-Aufkleber.

## Anpassungen

Den **Vereinsnamen** unten rechts (aktuell „Euer Vereinsname")
müsst Ihr noch ersetzen — entweder vor dem Drucken im HTML-Code
oder mit einem Stift/Sticker auf dem ausgedruckten Flyer.

Wenn Ihr **Vereins-Logo** zusätzlich draufhaben wollt, sagt Bescheid —
ich baue Euch eine Version mit Platz für Euer Logo neben dem Vorgestellt-Block.

## Was steht auf dem Flyer?

- Logo „Natürlich Abgesichert"
- Tag „Förder-Kooperation für Tierschutzvereine"
- Headline + kurze Erklärung
- 6 Themen (GOT-Erhöhung, OP vs Krankenvoll, Tarifdschungel,
  Haftpflicht, Eigenversicherung, Tier mit Vorgeschichte)
- Eckdaten-Box (Online-Zoom · Kostenfrei · Dialog · Mit Eurem Logo · Spende pro Vertrag)
- **Zwei leere QR-Code-Felder** (zum Aufkleben): Anmeldung + Termin-Buchung
- Otto-Kontakt (Adresse · Tel · E-Mail · §34d-Reg.-Nr.)
- Platz für „Vorgestellt von [Vereinsname]"
